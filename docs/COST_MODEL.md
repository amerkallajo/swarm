# Cost Model

Prices are planning estimates and must be checked against current vendor pages before purchase.

## Lean initialization

- GitHub private repository/Actions: free tier first; paid only for higher limits or team controls.
- Supabase: free project for development; Pro becomes justified by production backups, compute reliability, storage or usage.
- Netlify: free preview usage first; paid when bandwidth/build concurrency/team controls require it.
- Apify: free/low-credit bounded tests; paid when qualified-lead yield per dollar is proven.
- Gmail API: normally no direct API charge, but Workspace may be needed for professional sender identity and administrative controls.
- Telegram Bot API: no direct fee.
- LLM: use small models for extraction/classification, deterministic rules for gates, and premium models only for final audited personalization/preview briefs.
- Browser/Lighthouse/axe: local open-source tooling; hosted browser service only when reliability or IP geography proves necessary.
- Email verification: defer; start with syntax, DNS/MX and cautious provider/bounce handling. Pay when bounce reduction exceeds verification cost.
- Observability: structured database/system logs first; Sentry paid tier only after event volume/response needs justify it.
- Worker hosting: local development; a small container service only when continuous reply/webhook processing is approved.

## Cost ledger

Record estimated and actual units/cost by vendor, operation, job and lead. Report cost per discovered, validated, qualified, contacted, interested, previewed and won lead.

## Hard controls

Per-run Apify item/compute caps; maximum pages and seconds per audit; screenshot count; LLM token/model allowlists; email verification quota; daily sends; preview builds/deploys per lead; worker concurrency; vendor daily/monthly budgets. At 70% alert, 90% throttle, 100% pause.

## Purchase gate

No paid service or plan is created during initialization. A purchase proposal must state problem, expected monthly range, free alternative, measurable trigger, cancellation path and data-processing implications.
